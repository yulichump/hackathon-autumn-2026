# Invoice Keeper — бекенд

Напоминания о регулярных платежах: FastAPI + SQLite + Telegram-бот.
Администратор вносит платежи, бот за 3 дня до срока пишет в Telegram-чат, пользователи отмечают оплату.

Описание API для фронтенда — [API.md](API.md). OpenAPI-спецификация — [docs/openapi.json](docs/openapi.json),
[docs/openapi.yml](docs/openapi.yml). Swagger после запуска: http://localhost:8000/api/v1/docs

## Запуск

Нужен Python 3.11+.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните значения (см. ниже).

```bash
python -m app.seed
```

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

База — файл `data/invoice_keeper.db`, данные сохраняются между перезапусками.

## Настройки `.env`

| Переменная | Назначение |
|---|---|
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | единственный администратор; создаётся/обновляется при старте |
| `SECRET_KEY` | ключ подписи JWT |
| `TIMEZONE` | единый часовой пояс для «сегодня», просрочек и напоминаний (по умолчанию `Europe/Moscow`) |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | чат, куда приходят напоминания |
| `REMIND_DAYS_BEFORE` | за сколько дней напоминать (по умолчанию 3) |
| `REMINDER_CHECK_INTERVAL_SECONDS` | как часто проверять сроки |
| `WEBHOOK_URL` | необязательно: дублировать оповещения POST-запросом |
| `CORS_ORIGINS` | адреса фронтенда через запятую или `*` |

### Как подключить Telegram

1. Создайте бота у @BotFather, токен → `TELEGRAM_BOT_TOKEN`.
2. Добавьте бота в групповой чат (или напишите ему в личку), запустите бекенд и отправьте в чат `/chatid`.
3. Полученный ID → `TELEGRAM_CHAT_ID`, перезапустите бекенд.

Команды бота: `/upcoming`, `/overdue`, `/summary`, `/chatid`, `/help`. В напоминании есть кнопка «✅ Оплачено».

С одним токеном бота должен работать один экземпляр бекенда: Telegram отдаёт обновления (кнопки и команды)
только одному получателю, иначе в логе будет `Conflict: terminated by other getUpdates request`.
Напоминания при этом не задвоятся — отправка атомарно отмечается в БД.

## Тестовые данные

`python -m app.seed` создаёт (если их ещё нет):

- пользователей `user1 / user1pass` и `user2 / user2pass`;
- «Аренда офиса» 50 000 RUB ежемесячно (первый период оплачен, следующие прошедшие — просрочены);
- «Сервер Aeza» 20 USD — срок через 2 дня, напоминание уйдёт сразу;
- «Подписка на сервис» 15 EUR — срок через 10 дней;
- «Домен» 1 500 RUB ежегодно — просрочен на 5 дней.

Администратор — из `.env`.

## Правила

- Каждый период — отдельная запись со своим сроком и статусом. Оплатили текущий → сразу появляется следующий. Прошлые периоды не удаляются.
- Ежемесячный платёж считается от исходной даты; если такого числа в месяце нет — последний день месяца (31.01 → 28.02 → 31.03).
- Просрочка — со следующего дня после срока; оплата в день срока — вовремя. Оплачено позже срока — помечается просрочкой, исправление фактической даты её пересчитывает.
- Напоминание: неоплаченный период активного платежа, до срока ≤ 3 дней. Отправляется один раз (отметка в БД ставится только после успешной доставки). Платёж добавлен позже чем за 3 дня → напоминание сразу. После срока — одно сообщение о просрочке.
- Удалённый платёж: скрыт из списка, напоминаний нет, история оплат сохранена.
- Суммы по валютам считаются отдельно, без конвертации.
- Пользователь не может создавать/удалять платежи и управлять пользователями — проверяется на уровне API (`403`).

## Структура

```
app/
  main.py           приложение, lifespan, запуск фоновых задач
  config.py         настройки из .env
  models.py         SQLAlchemy-модели
  schemas.py        Pydantic-схемы
  payments.py       расписание периодов, просрочка, итоги
  notifications.py  напоминания, команды и кнопки бота
  telegram.py       клиент Telegram Bot API
  routers/          эндпоинты
  seed.py           тестовые данные
scripts/export_openapi.py  выгрузка docs/openapi.json и docs/openapi.yml
```

Обновить OpenAPI-файлы после изменений API:
```bash
python scripts/export_openapi.py
```
